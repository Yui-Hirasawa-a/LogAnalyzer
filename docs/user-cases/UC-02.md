# UC-02_AnalyzeLog.md — Проаналізувати журнал
Мета: отримати основну статистику HTTP-запитів.
Актор: користувач.
Передумова: є активний журнал із коректними записами.

Основний сценарій
1. Користувач обирає «Проаналізувати журнал».
2. Програма підраховує загальну кількість запитів, кількість відповідей 4xx і 5xx та кількість унікальних IP-адрес.
3. Програма показує статистику в консолі.
Альтернативний сценарій: якщо активного журналу немає, програма пропонує спочатку відкрити файл.

Результат: статистика поточного журналу доступна для збереження у звіт.
