# UC-01_OpenLog.md — Відкрити журнал
Мета: завантажити записи з локального журналу Nginx.
Актор: користувач.
Передумова: програму запущено.

Основний сценарій
1. Користувач обирає «Відкрити журнал» і вводить шлях до файлу.
2. Програма відкриває файл і читає його рядок за рядком.
3. Програма завантажує коректні записи й показує кількість завантажених і пропущених рядків.
Альтернативний сценарій: якщо файл недоступний, порожній або в ньому немає коректних записів, програма повідомляє причину й дозволяє вибрати інший файл.

Результат: завантажений журнал стає активним і доступним для аналізу.
