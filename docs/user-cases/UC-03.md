# UC-03_SaveReport.md — Зберегти звіт
Мета: зберегти результати аналізу в текстовий файл.
Актор: користувач.
Передумова: аналіз активного журналу завершено.

Основний сценарій
1. Користувач обирає «Зберегти звіт» і вводить шлях до папки.
2. Програма створює .txt-файл з унікальною назвою та записує в нього назву журналу, статистику й кількість пропущених рядків.
3. Програма показує повний шлях до збереженого файлу.
Альтернативний сценарій: якщо аналіз ще не виконано, програма пропонує його запустити. Якщо запис не вдався, користувач може вибрати іншу папку й повторити збереження без повторного аналізу.

Результат: звіт збережено у вибраній папці.
